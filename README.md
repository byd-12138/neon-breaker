# NEON BREAKER · 霓虹破碎者

一款单文件、无依赖的霓虹风打砖块街机小游戏。直接用浏览器打开 `index.html` 即可游玩。

## 操作

| 操作   | 方式                             |
| ---- | ------------------------------ |
| 移动挡板 | 鼠标 / 手指拖动，或 `←` `→`（`A` / `D`） |
| 发射光球 | 点击画面 / 轻触画面 / `空格`             |
| 暂停   | `P` / `Esc`，或右上角暂停按钮           |
| 声音开关 | 右上角喇叭按钮，或 `M`                  |

## 玩法

- 击碎全部光砖即可进入下一关，关卡越深球速越快。
- 连续击砖会累积连击倍率（最高 ×5），碰到挡板或掉球后中断。
- 击碎砖块有概率掉落道具：`W` 加宽挡板、`3×` 多球、`S` 减速、`L` 自动激光、`♥` 生命 +1。
- 每关通过会获得奖励分；生命归零则游戏结束。
- 最高分保存在浏览器 `localStorage` 中。

## 特点

- 纯 HTML / CSS / Canvas 2D / 原生 JS，单文件、零依赖。
- 高 DPI 自适应，桌面与手机竖屏均可游玩。
- 预渲染砖块精灵、粒子、拖尾、屏幕震动与合成音效。
- 完整状态流：开始、发球、暂停、过关、结算、重开。

## 运行

双击打开：

```text
index.html
```

或在本目录启动一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。
